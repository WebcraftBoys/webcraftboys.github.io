# Webcraft social links

The article pages use one shared social-link configuration so you only need to edit the profile URLs once.

Open:

`js/social-links.js`

Replace the five placeholder URLs in `WEBCRAFT_SOCIALS` with the real Webcraft profiles for:

- Instagram
- Facebook
- X
- YouTube
- GitHub

The links are displayed in the top bar of the Articles index and individual article pages.
