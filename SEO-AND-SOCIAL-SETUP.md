# Webcraft website update

## Social links
Edit `js/social-links.js` once. Add the real Instagram, Facebook, X, YouTube and GitHub profile URLs. The same links appear in the top utility bar and footer across all public pages.

## Public navigation
Home · Work · Services · Articles · About · FAQ · Contact · Start a project

## Articles
New article pages live in `pages/articles/`. Add new articles to the Articles index and `sitemap.xml`.

## Process page
The old Process URL is retained as a noindex compatibility redirect to Articles so old links do not become broken. It is excluded from the sitemap.

## Search Console
After publishing, submit or re-submit `sitemap.xml`, then inspect the Articles index and individual article URLs.
